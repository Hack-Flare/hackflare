API

Automate all of it

REST and gRPC APIs cover everything the dashboard does. Script your records, hook DNS into CI, or build your own tools on top.

API reference
REST gRPC Example request 
# add an A record to your zone
curl -X POST {{ api_base_url }}/api/v1/dns/zones/yourproject.dev/records \
  -H "Authorization: Bearer $HACKFLARE_TOKEN" \
  -d '{ "type": "A", "name": "api", "value": "192.0.2.24" }'

# → 201 Created
gRPC example
# the same call over gRPC
grpcurl -H "authorization: Bearer $HACKFLARE_TOKEN" \
  -d '{ "zone": "yourproject.dev", "type": "A", "name": "api", "value": "192.0.2.24" }' \
  {{ api_host }}:443 hackflare.dns.v1.Dns/CreateRecord

# → record created
